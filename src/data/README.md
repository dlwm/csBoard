# Dust II map data

`de_dust2.json` is the parsed CS2 navigation mesh used by Awpy, sourced from:

https://github.com/pnxenopoulos/awpy/blob/main/tests/de_dust2.json

It contains 2,248 navigation areas from NAV format version 35. The web preview
renders the area corners as a lightweight Three.js walkable-surface mesh. This
is navigation geometry, not Valve's visual/material map assets.

Awpy is MIT licensed. The underlying CS2 map content remains subject to
Valve's terms and is not redistributed here as a visual asset.
