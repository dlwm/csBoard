# Operation guide example

A compact replay excerpt from falcons-vs-vitality-m3-dust2.dem. Round 22 is retained and selected by default. The other included rounds preserve a real repeated-utility group for the recommendation exercise.

Contains recorded player snapshots, throw actions, trajectories and effects; excludes voice and the original .dem file. It is a tutorial example, not the complete match.

Regenerate after parser/cache changes with `make guide-example DEMO="path/to/source.dem"`. Reuse the local preparation with `make guide-example ARGS=--reuse`.
