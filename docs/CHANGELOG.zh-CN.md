## [1.20.2] - 2026-10-05

### 新增

- 人物模型使用带厚度的枪械轮廓，支持第一视角回放展示。
- 桌面端支持检查更新、下载安装包及完整性校验，展示下载进度并支持取消；Windows 可启动安装，macOS 可打开更新磁盘镜像。
- Windows 和 macOS 可从本地 CS2 游戏资源导入地图模型和支持的界面图标，支持自动检测 Steam 游戏库、手动选择目录、空间提示、进度展示和取消。

### 改进

- Windows 安装时可选择安装目录，以及为当前用户或所有用户安装。
- 下载入口名称改为“桌面端下载”。

### 修复

- 修复回合选择菜单展开后超出工作区边缘的问题。

## [1.20.1] - 2026-10-05

- 道具播放及第一视角播放共用底栏进度条，新增展示轨迹和展示道具效果开关，控制当前地图全部速记的静态总览。

- “回合浏览”更名为“对局回放”，自制录像与标准对局共用列表；非常规 Demo 可点击继续解析，自制类别显示“自制DEMO”标签。

### 改进

- 统一各菜单的边栏外观与间距，包括视角演播，并统一折叠操作与工作区布局。

### 修复

- 操作助手及主视图角落提示随边栏与底栏变化保持正确位置，横屏小窗口中可滚动访问助手输入区。
- 修复非常规 Demo 继续解析的进度与完成统计，自制 DEMO 标签固定在主视图左下角，收栏后画笔保持单行，并区分菜单页签与设置入口。
- 道具人物动作仅保留至出手，飞行轨迹随播放逐段生成；补齐前跳投的短促方向提示，按键图改为纯方向箭头。
- 修复地图与列表重叠、底栏排列及浮层偏移，死亡选手不再展示武器与库存。
- 修复演播进度条被遮挡、地图控件贴边、其他菜单残留对局人物、拖动进度条重复人物，以及道具轨迹被地面错误遮挡的问题。

## [1.17.0] - 2026-09-30

### 调整

- Demo 解析统一使用固定提交的 `dlwm/demoinfocs` fork，共用 Go 适配层生成原生程序与 WASM；源码构建自动准备依赖，应用自带编译后的解析器。
- 合并回放、分析与投掷前的位置采样计划，每段 Demo 共用一次解码扫描；保留真实烟雾日志和火焰格子，烟雾字节仅读取新增部分，并更新不兼容的解析缓存。
- SQLite 存储改为 Go，兼容既有数据库、压缩缓存、备份与恢复流程。
- HTTP 解析及离线分析工具统一使用 Go WASM；HTTP 请求结束释放解析会话，离线报告保留投掷事件来源与未知速度。
- 移除 Rust/Cargo 编译依赖、旧解析器产物与补丁、原生 npm 解析依赖；构建、安装包检查、GitHub Actions 和 Docker 同步改用 Go。

### 修复

- 从 Source 2 检查点恢复输入指令基线，避免重复派发输入事件或被旧检查点回滚状态。
- 兼容 macOS `vm_stat` 实际出现的两种页大小头格式，避免内存统计缺失导致解析一直排队。

## [1.16.0] - 2026-09-28

### 新增

- 桌面端引入独立 Rust 原生解析组件，使用 SQLite 和压缩文件保存存档及 Demo 缓存，避开浏览器存储配额。前台继续使用 Electron、Three.js 和 Yjs；Web 通过共享平台接口保留 WASM 与 IndexedDB 实现。
- 支持多 Demo 同时解析及单 Demo 原生多线程采样，新增均衡（默认）、极速、自定义模式。任务共享 CPU 预算，根据可用内存、输入大小和观测占用决定启动时机，可自定义并发数量、线程上限和内存预算。
- 新增桌面管理：查看任务进度、取消任务、线程与内存诊断、空间占用、手动清理缓存、校验备份及重启恢复。恢复时保留原数据副本；可为本次运行启用任务期间防自动休眠。
- 支持将旧 IndexedDB 存档与 Demo 缓存迁移到原生存储，保留旧数据库，并避免覆盖较新的原生记录。

### 调整

- 采样时跳过不含目标 tick 的完整快照片段，复用解析器 Huffman 表，减少大型 JSON 载荷的额外复制。事件、烟火日志、按键状态及不能安全分段的属性继续顺序解析。
- 分析计算、大型导入导出序列化和演播载荷处理移至桌面后台进程；通过文件和流式缓存读取减少 Electron 主进程的大数据中转，批量缓存检查改用小型摘要。
- 桌面窗口隐藏或最小化时暂停 3D 绘制，原生解析继续；回放按实际经过时间推进，避免延迟回调拖慢播放时钟。
- 重设计资源包管理界面，按资源类别展示完整度及逐文件导入结果；统一 CSBoard 应用名称和图标，macOS 打包应用使用 CSBoard 身份启动。
- 增加 GitHub Actions 检查与三目标打包自动化，包含版本校验、包内存储检查、SHA-256 和草稿 Release。清理源码字符串断言，补充行为、原生存储及发布接口测试；缺少原生测试组件时明确失败。
- 发布安装包限定为 macOS Apple Silicon、Intel Mac 和 Windows amd64，使用明确区分架构的命令及文件名。合并重复的 npm／Make 入口，带模型测试包改用 `desktop:prepare -- --local-models`。
- 分离 Web、桌面页面与后台任务的构建输出，通过平台适配层共享解析及数据接口。`desktop:prepare` 构建应用，`desktop:start` 启动已有应用包，`desktop:dev` 保留 Electron 调试入口。桌面源码构建需要 Rust/Cargo 和 C 工具链，安装后的应用自带原生组件。

### 移除

- 移除当前 AI 指南、模型访问集成和 WebMCP 注册，后续重新设计；保留数据分析与导出功能。

### 修复

- 原生解析保留跨快照片段的按键状态，保持烟火输出顺序及类型化数组存储与现有回放兼容。
- 完善排队及运行任务的取消、重复 Demo 任务拦截和原生存储进程退出后的连接恢复；macOS 原生可执行文件改为原子替换，避免旧可执行文件签名缓存导致启动失败。

### 验证与限制

- Apple M4、16 GB 内存、8 Hz 采样下，299 MB Nuke 完整原生解析由 39.3 秒降至 15.0 秒，282 MB Inferno 由 45.2 秒降至 16.3 秒；Electron 中两份 Demo 共享 4 线程预算，逐个解析约 18.2 秒，并发约 10.3 秒。这是包含多项优化的样本实测，不代表所有设备和 Demo 的固定提速。
- 三份 Demo 完整输出与串行基线在浮点容差内一致，87 项行为／集成测试（无跳过）及隔离目录桌面检查通过。内存预算控制任务启动，不是进程硬性上限；Intel Mac／Windows 实机验证及签名、公证发布包尚未完成。

- 演播底栏收回画面中栏，左侧模型、右侧时间轴；窄桌面窗口通过按钮展开模型选项，避免挤掉进度条。
- 奔跑尾气缩短、缩小并降低透明叠加，仅在持续向前位移时生成，避免小范围来回移动或缺失位置样本时堆成烟团。
- 击杀栏按已知武器名的最长前缀匹配图标，兼容 `usp_silencer_txz09`、`glock_vip` 等 Demo 变体，同时保留原始事件名称便于追溯。
