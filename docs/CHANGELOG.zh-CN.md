## [1.15.0] - 2026-09-22

### 新增

- 回合浏览与视角演播新增同阵营监视器：可选择主视角、切换阵营，在右侧单列查看队友视角及小准星；死亡视角变黑并显示斜叉。
- 新增视角演播存档：从回合浏览保存一个命名时间段，选择存档即开放房间；访客全屏查看下载进度，完整接收并保存到本地后才播放。演播独立保留 Demo、时间轴、镜头、监视器和模型控制，不显示回合比分等比赛专属 HUD。
- 协作存档、视角演播片段和道具速记分别支持可拖拽的文件夹树；保存时可选目录，根目录不可编辑、允许同名文件夹，删除文件夹只把内容上移。
- Cloudflare Worker 前端构建可选用本地 SVG 图标资源包；缺失图标沿用内置 UI，地图模型仍从外部读取，不纳入资源包。

### 调整

- 回放烟雾改为更浓密、柔边的单一体积效果，保存及导入道具时保留记录的烟雾形状。
- 回放烟雾新增 HE「炸烟」视觉：以记录的爆点短暂挖开烟雾并逐渐回填，明显隔墙时不生效；演播片段若从炸烟中途开始也会保留相关 HE 事件。视觉范围为近似值，并非官方公开的半径常量。
- 演播底栏收回画面中栏，左侧模型、右侧时间轴；窄桌面窗口通过按钮展开模型选项，避免挤掉进度条。
- 奔跑尾气缩短、缩小并降低透明叠加，仅在持续向前位移时生成，避免小范围来回移动或缺失位置样本时堆成烟团。
- 击杀栏按已知武器名的最长前缀匹配图标，兼容 `usp_silencer_txz09`、`glock_vip` 等 Demo 变体，同时保留原始事件名称便于追溯。

## [1.14.0] - 2026-09-14

### 新增

- 桌面端新增资源包入口，支持原生多文件 SVG/GLB 导入、逐文件结果、完整度清单、校验后替换及磁盘持久化。缺失图标沿用默认 UI，缺失模型使用 NAV、隐藏模型控制且不自动访问 OSS；导入后手动重新加载应用。正式安装包不再携带模型，仅独立的本地测试构建可内置模型。
- 数据分析支持按准确的已选 Demo ID 分析单个回合，提供双方完整站位时间线、交战与炸弹事件、道具及可选轨迹、分页 JSON、数据覆盖诊断和基础提示词；区分客观事件与战术意图、回防、假打等推断。使用原始 Demo tick，不改变当前回放。
- 数据分析新增中英俄 AI 接入教程，包含就绪检测、可复制提示词、桌面实验模式启动方法和隐私说明。AI 界面及 WebMCP 工具注册仅限 Electron 桌面端，通过隔离的预加载标识识别；普通浏览器即使开启 WebMCP 也不会注册工具。API 可用不代表模型已连接。

### 调整

- 将本地游戏来源地图、UI 测试素材和 VPK 统一收纳到 `.local/official/`，同步开发、下载/导出脚本、Docker 和本地测试构建路径；Demo 样本与生成预览仍单独存放。
- 2D 雷达改由内置 NAV 数据生成离线顶视图，不再依赖静态雷达图片；与人物标记共用正方形边界、留白和楼层切分，修正地图拉伸及 Train 楼层划分。各楼层内按地面高度显示深浅，高处更亮，重叠时优先显示较高地面。
- 3D NAV 通过共享顶点、法线和高度配色平滑显示，移除区域边线及其开关。
- 调整枪械、匕首、道具、C4、拆弹钳、阵营、护甲及 HUD 图标；空心盾表示护甲，中央带圈表示头甲，并修正装备和道具储备图标尺寸。
- 地图名称改为更大的国际化彩色标签，不再额外展示地图徽标。人物使用国际象棋兵式标记，区分站立与蹲姿，并同步回合浏览及协作面板的装备和瞄准线高度。
- 同步文档与许可证范围，将第三方许可证声明随 GPL 许可证一同提供于网页和桌面构建。

### 鸣谢

- 感谢 React、Three.js、three-mesh-bvh、LaihoE/demoparser（含 Rust/WASM 解析器）、Yjs、y-websocket、y-protocols、lib0、ws、Electron、Vite、electron-builder、Wrangler、Fontsource，以及 Space Grotesk / DM Mono 字体作者。第三方许可证与声明见 THIRD_PARTY_NOTICES.md，各项目继续遵循原有许可证。

## [1.13.1] - 2026-09-09

### Added

- 支持视觉的 WebMCP 模型现在可截取当前 3D 画布，并选择 WebP、JPEG 或 PNG、受限宽高、编码质量、适配方式及是否附带上下文；截图会同时说明相机投影、地图、Demo 时间点和当前数据分析筛选。
- 新增俄语 README 与更新日志，为三种文档语言补齐直接跳转入口，修复已有文档中的失效链接和图片路径，并让离线更新日志弹窗跟随俄语界面显示。

### Fixed

- Demo 道具解析现在始终包含非投射物实体，因此 HLTV 比赛即使已有正常的 `grenade_thrown` 事件，也会保留其记录的 `CInferno` 火点；解析器内部的状态去重会限制新增记录量，同时提升 Demo 缓存版本，让受影响的源文件重新解析一次，不再继续显示一小团默认火焰。
- 协作工作区存档由容量受限的 `localStorage` 迁移至 IndexedDB，连续保存会严格按照用户操作顺序写入；旧存档仅在迁移成功后删除原副本。包含轨迹、烟雾体素和火点的 Demo 帧不再过早提示“浏览器本地空间不足”。
- 道具速记及其记录的轨迹、烟雾体素和火点也迁入同一个 IndexedDB 本地数据仓库，并支持顺序写入与安全的旧数据迁移；同时移除从未读取的大型房间快照写入并清理遗留键，仅将确实很小且需要同步读取的设置保留在 `localStorage`。
- 恢复批量解析接入时遗漏的小游戏生命周期：解析超过 3 秒会自动弹出小游戏，批次完成或快速命中缓存时会正确取消并收起，用户在当前批次中主动关闭后也不会再次打扰。
- Space Grotesk 与 DM Mono 改为随前端打包，不再运行时依赖 Google Fonts；所有界面和数据字体统一使用跨平台字体变量，对字体未覆盖的中文和西里尔字符在 Windows 上明确回退到 Segoe UI、微软雅黑 UI、Cascadia Mono 或 Consolas，避免落入生硬的旧式通用字体。

## [1.13.0] - 2026-09-08

### Added

- Electron 桌面端新增可选启用、以数据分析为主的 WebMCP 集成：用户自己的模型可读取当前选手、Demo、阵营、双方经济、回合阶段、道具类别与事件位置筛选，按页获取紧凑的 KD／区域时间／道具 JSON，并可按需取得投掷物轨迹；同时提供字段语义及基础分析提示词。另保留 6 个可感知状态的工作区导航与回放工具。前端和内置地图模型由具备源隔离的只读本机回环服务承载，固定本机源可延续桌面存储，单实例锁可避免端口冲突。
- Electron 安装包现在会把本地 GLB 地图模型作为可流式读取的外部资源一并打包；桌面端逐个模型优先读取安装包内容，内置文件缺失或损坏时自动回退到已配置的 OSS。
- 燃烧弹与燃烧瓶改为读取 Demo 中权威的 `CInferno` 火点，不再依赖相邻 NAV 面猜测覆盖范围；进一步增强的累加式 metaball 张力场会将相邻火点拉成一块单色不规则表面，自动填充被火焰完整包围的无火内圈且不留下内部边界，仅在整体外轮廓保留透明柔边，再投影到最近的同层 NAV 地面；既消除颗粒串联观感和立体火苗穿模，也能跟随斜坡与高度变化。火焰帧仅在状态变化时保存，旧数据仍使用原 NAV 效果兜底，并会随新保存的道具速记和协作帧一同保留。
- 点击 CSBoard 品牌旁的构建版本即可打开格式化、可滚动且完全离线的更新日志弹窗，并按当前界面语言选择内置中文或英文文档。

### Fixed

- Q 轮盘添加的火焰现在使用确定性的烟雾式默认范围，并复用真实火焰的单色融合 NAV 投影；移除旧的相邻 NAV 面片、分层火圈和脉冲圆环，拖动范围时仅做轻量缩放预览，松开后再按照新覆盖区域重新生成并贴合 NAV 地面。
- 修复回合浏览中无法保存投影火焰的问题：通过共用的 `inferno_startburn` 落地事件，将爆开后新建的 `CInferno` 实体重新关联到原燃烧瓶飞行段；保存操作条改为显示在实际点击的火面位置，而不是投影组的场景原点。
- 修复大型 Demo 在解码道具时耗尽浏览器 4 GiB WASM 内存的问题：持久化的 `CInferno` 数组会在列数据／AoS 分配前于解析器内部去重，手持道具状态也仅在有效投掷时间发生变化时输出；完整保留真实火焰格和投掷采样，同时移除数百万条冗余记录。

## [1.12.0] - 2026-09-07

### Added

- 道具速记列表支持悬停或键盘聚焦时预览完整轨迹和落点效果，并将镜头中心移至该落点效果；离开列表后恢复原镜头，缺少落点数据的旧手工速记才退回出手位置。
- 切换协作帧时自动播放目标帧包含的道具：轨迹严格按照记录的 tick 时间及不等间隔采样推进，道具效果在记录的爆开 tick 出现，烟雾按爆开后的记录时段扩散，结束后保留目标帧的完整静态状态；普通的面板或存档恢复仍保持静态展示。
- 悬停协作面板人物列表时，镜头会进入对应人物保存的第一人称眼位和瞄准方向，临时使用第一人称视野并隐藏该人物自身模型；鼠标离开列表后恢复原视角。
- 从回合浏览保存帧时，帧内仍生效的 Demo 道具会作为匿名道具进入协作面板，并完整保留轨迹和已记录的烟雾体素形状；悬停匿名条目会直接聚焦场景中已有的道具效果，临时切换为 20% 镜头透视并匀速环绕，离开列表后恢复原镜头及透视设置；匿名道具可直接删除，也可通过删除键旁的保存键补全名称与投掷说明，保存后会写入道具速记并转为正常引入道具。
- 协作面板的每条存档在删除键旁新增独立保存键：点击后先明确确认覆盖，并以当前内容替换目标存档；存档列表底部的保存入口则始终创建新存档。
- 协作面板的道具导入列表支持悬停预览：划过候选项时会临时显示道具效果和轨迹，并平滑将摄像机聚焦到落点；只有确认后才会加入当前战术帧。
- Demo 解析新增下载器式批量任务：不同文件会作为独立 Demo，连续编号的分片仍自动合并；性能合适的桌面设备并行运行两个解析器，受限设备自动顺序处理。全部结束后只汇总成功/失败数量而不自动播放；开发模式可展开查看各任务的来源、解析阶段、缓存环境、耗时、比赛摘要、警告与错误诊断，便于追溯问题。
- Demo 回放新增 CS2 烟雾体素形状：内置解析器会保留并增量输出每颗烟的网络体素日志，3D 画布按环境影响后的占用种子展示烟团，不依赖 GLB 地图模型；每个记录的占用体素严格贡献一个正确间距的密度源，三轮进一步增强的张力平滑会先闭合间隙，再由 Marching Cubes 提取一层连续不规则外壳；外壳采用不透明正面渲染和柔和补光，内部及后方轮廓不会重叠且覆盖范围仍清晰可读；新保存的 Demo／数据分析道具会携带对应烟雾体素帧，旧速记、手工道具和预览则使用同一外壳渲染器的确定性兜底体积，不再显示为分离球体；完整烟团统一按 1.1 倍展示，保持体素尺寸、间距和外轮廓之间的比例；实测坐标映射为解码 A/B/C 到场景 +B/+A/+C。

### Fixed

- 回合浏览的死亡位置简化为贴近地面的叉号标记，移除容易被误解为范围的外围圆环。
- 压缩匿名 Demo 道具的本地存储：轨迹采样和最终烟雾体素只保留一份，不再在内嵌速记元数据中重复整段烟雾日志；旧匿名存档会在下次保存时自动迁移压缩。仅在用户补全信息时重组可移植速记，若道具速记写入失败则保持匿名状态，不再错误显示为已保存。
- 协作画线权限现在会在每次渲染时与当前战术帧同步，修复切换面板或帧后地面左键拖动画线失效的问题；画线结束后也会正确释放相机控制状态。
- 道具速记烟雾的扩散过程及协作面板可调烟雾现在统一保持标定后的 1.1 倍等比例尺寸；烟雾速记导入协作面板时会保留最后一帧体素形状，不再退化为通用烟球。
- 修复入口与 Three.js 画布拆分后遗漏的运行时依赖，包括数据分析道具轨迹构建及点位选择回调。
- 楼层淡化着色器现在会跳过场景中的占位材质，并兼容未初始化 `userData` 的导入材质，避免动画循环逐帧重复报错。
- 修复内置 Demo 解析器将 Source 2 中编号超过 2047 的实体句柄错误截断为 11 位的问题，改用完整 14 位索引，恢复缺失选手的坐标、状态、装备归属和事件关联；对确实缺失 pawn 数据的情况仍保留 controller 兜底与明确提示。
- Demo 解析时新增前台运行提醒，明确说明切换标签页、最小化浏览器或锁屏可能显著拖慢后台页面处理；提示会同时显示在解析进度条和等待小游戏中。

## [1.11.0] - 2026-09-06

### Added

- 新增俄语界面支持，覆盖主工作区、Demo 数据分析、操作教学、解析设置、相机控件、回合结果与解析等待小游戏；语言切换扩展为中/英/俄三种并持久化，日期也会使用对应区域格式。
- 数据分析选手改为可搜索多选：选中项以标签展示并可快速移除，人物名称、轨迹、逐选手回合经济、KD 事件、道具事件、区域时间热力、Demo 可用范围及共用时间轴均会按多选结果正确聚合。

### Changed

- 每个已加载 Demo 只建立一次选手名称索引；选手切换时延后执行高开销数据集重建，区域热力按“选手-回合”分组计算，并在增删选手时尽量复用当前 Demo 筛选。
- 继续缩减 `main.jsx`：完整 Three.js 画布、运行配置、默认数据加载、国际化字典、协作工作区标准化、响应式/雷达/楼层 hook、Demo 展示派生状态、道具保存转换、道具回放时序、全局顶栏、视口工具、模型加载状态与工作区弹窗均已迁入职责明确的独立模块；Three.js 画布内部又拆出了动态参数同步、Demo 选手渲染和画笔线条生命周期。
- 将全部支持地图的 NAV 解析数据构建进前端，移除运行时 NAV 下载与旧解析接口依赖，并为离线使用保留地图几何兜底。
- Docker 服务改为直接读取只读挂载的 `.local/maps` GLB 模型，不再在启动时运行资源下载服务。
- 暂时隐藏 T/CT 出生区域和炸弹安放区模型，等待后续替换为更合适的展示方案。

### Fixed

- 修复 Docker 构建在排除 `.git` 后无法把传入的 v1.11.0 构建版本交给 Vite 的问题。
- 修复地图切换时因不同地图 NAV 格式版本相同，导致新 GLB 与上一张地图的内置 NAV 错配的问题。
- Anubis 的默认 3D 环绕高度改为锚定最高可玩 NAV 表面，避免模型底部无意义几何拉偏中心。
- 移除 Demo 第一人称回放中重复的通用准星，保留带开火和开镜反馈的 POV HUD 准星。
- 将保留的 Demo POV 准星对齐到真实 3D 视口，不再按包含底部控制栏的整个舞台区域居中。
- 道具第一人称播放在出手后冻结投掷瞬间视角 0.3 秒，随后切换为投射物跟随镜头，不再跟随投掷者移动；爆开后恢复原地图机位。
- 相机机位现在会保存模型透视范围，且透视范围调至 0% 时会完全关闭透视开口。
- Farkle 五骰顺子现在可与第六颗计分骰 1 或 5 一起全选；反应测试改为按下时立即完成判定，不再等待松开。
- 数据分析中的道具记录现在可从出手点或落点打开并保存；hover 附近列表中的任一道具时会高亮其对应轨迹。
- 数据分析的附近道具列表改为更小的半透明样式；鼠标进入列表后，一旦移出便立即关闭。
- 语言切换按钮改为显示当前中文、英文或俄文状态，并通过悬停提示下一目标语言，避免按钮文案与页面语言错位。
