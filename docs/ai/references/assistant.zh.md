# 操作助手：会话记忆、上下文与工作流

**实验性功能，仍在持续改进。**

## 使用方式

在协作面板打开存档，配置支持 Chat Completions 工具调用的服务与模型。助手保留编辑人员、道具、效果、线条、帧、存档及房间的能力。默认系统提示词使用英文，代码带中文维护注释；只提供应用概念和工具规则，不注入预设战术教学。

助手的“学习”是持久保存并检索上下文，不是训练或微调模型。

### 会话与记忆

- 新会话不会删除之前的会话；下拉菜单切换，名称可修改。
- 每个会话独立保存消息、操作结果状态、可编辑记忆、上下文变化和工作流。切换会话不恢复存档或修改画布。
- 记忆可记录偏好、术语约定及确认事实；助手通过 `remember_context` 追加明确事实。已有猜测不应成为事实。
- 每轮提供最近完整对话轮次、记忆、当前快照和近期变化；`get_session_memory` 搜索更早保留的消息、操作结果及观测并分页。历史位置与对象 ID 不代表当前画布。
- 切换存档、帧、地图或房间保留会话记忆，但停止正在执行的旧计划。失败回复标记中断，不将未完成工具调用重放。
- 可导出 JSON 并在另一设备导入。导入创建独立会话，导入后不会自动执行任何工具、恢复画布或启动工作流。文件包含用户对话、记忆和操作观测，请按这些内容管理文件；不包含 API Key、服务配置、原始工具调用或截图。

桌面使用已有原生 records 存储，网页使用 IndexedDB，不把会话发送到 Yjs 房间。模型请求才把所需上下文发送到配置的服务。刷新后恢复会话；保存失败会明确显示，不能视为保存成功。

### 上下文观测

记录地图、存档名称及 ID、帧、功能面板、房间变化，以及人员／道具／效果／线条的新增、删除和属性变化。记录显示／编辑选项，功能按钮点击只表示操作请求，不证明操作成功；不读取输入框、密钥或桌面。画布通知经过短暂合并；另有 1.5 秒观察补充直接操作及协作变化。观测不推断修改者，也不是逐个鼠标事件录制；很快的中间状态可能合并。

画布快照记录对象 ID、位置、名称和关键属性，不发送完整 Demo 或道具轨迹。大型画布采用有限摘要并标记省略；准确编辑须读 `get_board_state`。最近 500 条观测持续保存，提示词携带近期预算内部分；手动偏好与已确认事实放在长期记忆中，不依赖变化日志永久保留。

### 工作流

在“会话记忆与工作流”中添加步骤，填写名称及指令，选择允许的工具，使用上下箭头排序，手动启动。每步依次运行同一个 agent loop，读取实时上下文并承接前一步对话。无允许工具的步骤仅生成文本。每步工具权限同时限制发送给模型的定义和实际执行入口，不靠提示词约束。

工作流最多 24 步。遇到工具错误、取消、需要用户输入的对话框或存档／房间切换时，停止后续步骤；已提交编辑保留。不会自动恢复、重复执行或回滚此前步骤。重新点击执行从第一步开始，运行前应核对可能重复的修改。目前是顺序指令编排，没有条件分支、定时任务、后台自动触发或可验证的完成条件；模型文字回复本身不证明目标达成。

## 三维视图

`inspect_board_view` 支持当前视角、俯视，以及围绕已知人员／NAV 位置的局部视角。局部视角可由助手设置 `azimuth`（Source XY 地面方位角，0° 朝 +X）和 `elevation`（高于地面的观察角度，15–85°），默认 45°／55°。观察采用临时相机，不移动主界面镜头。

截图隐藏建筑模型与原有地面渲染，并临时绘制当前楼层 NAV 地面；保留画布对象与编号。建筑模型仍可用于独立的射线诊断，但不进入截图。地面几何不包含真实墙体、箱体或完整报点，不能据此确认视线、掩体或道具覆盖。

启用图像输入才发送 JPEG；纯文本模型仍可读取投影、区域多边形、高差、连接和相对位置。截图像素通过 `resolve_view_point` 映射为 NAV 三角形候选，须核对多个楼层；不能估算 Source 坐标。每轮最多三次观察、请求最多两张图片；截图不跨轮重放，也不持久保存或导出。

## 边界与预算

- 最多 50 个会话，每个会话约 5,000 条显示记录；达到容量提示新建会话，不静默删除旧消息。单轮执行最多八次模型请求、二十四次工具调用、六次地点查询。
- 手动记忆最多 16,000 字符；单个新增事实最多 2,000 字符。导入文件最多 10 MB，校验格式与工作流工具名。
- 模型请求历史达到压缩阈值时，把较早内容转换为摘要，不拆工具调用与结果；原始会话供检索。关闭压缩后仍受传输大小和消息数的硬上限约束。
- 流式传输最多 32 MB；回复、推理和工具参数分别有限额。保留兼容服务要求的完整推理字段，不截断参数再执行。超限与中断不会自动重试。
- 破坏性操作仍需确认；等待确认后检查 revision，拒绝后停止当前计划。场景切换取消旧执行，避免修改错存档。
- 人员角色/C4、软投掷者绑定、计划时钟、帧条件与分支尚未实现，设计见后续设计（尚未实现）。

## 自动压缩设置

在“会话记忆与工作流 → 记忆”中启用或关闭自动压缩，并设置每个会话的阈值。默认启用，阈值为 60,000 个文本字符，可设 12,000–240,000；修改数值后离开输入框保存。字符数是序列化文本估算，不是模型 token 数。图像使用独立传输预算。消息数量接近安全上限也会触发整理。

压缩在下一次模型请求前触发，包括一次执行中的后续工具轮次。用当前配置模型发起无工具的摘要请求，界面显示“正在压缩上下文”，这会增加模型请求费用与耗时。旧历史按完整工具交换分组，保留当前用户请求和最近工具交换；摘要保留目标、偏好、成功结果、失败／取消、待办及所属存档和帧。原始推理不传给摘要模型；仍需重放的最新工具交换保留服务要求的完整推理字段。

摘要与覆盖的消息引用持久保存，刷新后无需重复发送已压缩文本。消息和操作观测不会因压缩删除，可通过会话检索查看；摘要输入可能采用长消息片段，不能把摘要视为无损压缩。导入会话重新生成内部摘要引用，避免外部消息 ID 影响本地会话。摘要失败、中断或返回工具调用时停止本轮，不自动重试，也不执行任何摘要请求中的工具。已提交的画布修改仍保留。

当前请求、实时状态和最新工具结果无法安全缩减时，实际上下文可能仍高于阈值；最终传输上限继续有效。阈值不是模型窗口的精确 token 上限。

工具列表、操作记录及执行提示使用中文／英文／俄文名称；工具列表悬停显示相应语言的说明，内部标识仅在悬停或键盘聚焦时显现，背景同步高亮。国际化不改变工作流存储的工具权限标识。

## 按需查阅使用文档

助手通过 `read_app_documentation` 获取随当前版本打包的参考资料，离线可读，无需读取任意文件或访问 GitHub。默认资料包括：

- `readme`：中文、英文、俄文应用说明，包含功能、支持地图、快捷键、当前限制和桌面性能／备份操作。
- `resource-packs`：中文、英文、俄文资源包说明，包含支持格式、导入、替换、容量与重新应用。
- `assistant`：操作助手说明，包含会话、记忆、上下文、工作流、视图、压缩和能力边界；目前原文为中文，其他语言查询明确返回语言回退信息，不伪称已有译文。

不传文档 ID 时返回目录、来源、语言、章节 ID 与标题；指定文档后按章节或分页读取。默认每页 6,000 字符，可设置 500–12,000，通过 `nextOffset` 继续。工具只允许资料清单注册的文档 ID，不接受路径；添加资料后目录与工具说明自动更新。可读内容统一由 AI 参考资料清单注册，应用与资源包资料只包含使用说明。开发文档、更新日志、许可证和未来设计方案不进入工具目录。

文档用于理解应用，不代表当前画布，也不增加工具权限。提示词只提醒按需查询，不提前装入整份文档，更不会恢复已移除的战术教学语料。
