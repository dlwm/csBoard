# 用户使用手册

[返回首页](README.zh-CN.md) · [English](user-guide.md)

## 从哪里开始

首次启动可开启操作指引，也可随时点击主视图右上角的 **?** 重新开始；悬停问号可查看快捷操作。内置精简示例包含 Falcons 对 Vitality 的 Dust2 第 22 回合，不需要先下载原始 Demo。

| 你想做什么 | 入口 |
| --- | --- |
| 看比赛、第一人称或多个队友视角 | 对局回放 |
| 找常用道具、观察选手路线和击杀位置 | 数据分析 |
| 保存并复习投掷，获取 getpos | 道具速记 |
| 排兵布阵、分阶段讲战术、多人一起编辑 | 协作面板 |

## 对局回放

选择一个或多个 Demo，等待解析完成后从本地列表打开。多段同场录像可合并；失败项可单独重试。非常规跑图录像可选择“继续解析”，之后以 **自制 DEMO** 播放，不显示标准对局的分析和战斗状态栏。

选择回合，用底栏播放、暂停、调整进度；默认从冻结结束播放，向前拖动可看冻结阶段。点击时间线事件定位击杀或下包；点击选手切换第一人称，监视器可同时观察队友。语音默认静音，顶栏可开启并筛选全部／T／CT，悬停调整音量。

“保存当前帧”将当前布局保存供协作面板编辑；保存时间段会生成独立自制 DEMO，保存在本地列表，也可按需分享。这是回放数据，不是重新生成游戏 `.dem` 文件。

## 数据分析 → 道具速记

1. 选地图、选手和 Demo，再按回合、阵营或经济筛选。
2. 切到 **道具事件**，按道具类别查看起点、轨迹和效果位置；默认位置模式，可切换热力。
3. 左侧推荐将相似投掷归组，仅推荐出现至少 4 次的组。悬停预览，“聚焦同组”只看该集合，“添加代表道具”保存代表投掷。
4. 在 **道具速记** 中命名、分文件夹、播放准备与投掷动作、切换第一人称，并复制 getpos。也可直接粘贴游戏 getpos 创建速记。

推荐分数是排序参考，不代表成功率。记录中没有的按键或烟体不能凭空还原；效果与可用信息取决于 Demo 来源。底栏“展示轨迹／展示道具效果”控制全图浏览，可导入导出 JSON 保存速记库。

## 协作与存档

回放里保存的帧可在协作面板打开。添加人物、拖动站位、调整朝向，使用道具和笔刷表达配合；插帧或复制帧建立下一阶段，再保存到本地存档。人物颜色便于识别，相机与预设不随其他成员强制同步。

开放房间后发送房间号，其他人通过“加入房间”输入。加入成功前保留本地画面；连接失败时检查服务器地址再重新加入。房间是共同编辑工作区，重要内容请另存本地存档。存档与速记使用各自的文件夹。

## 视图与常用操作

3D 和俯视 2D 可切换；2D 支持缩放、旋转，多层地图并排展示。小地图可切换纯地图和带名称的点位地图。导航地面、模型透视、楼层选择帮助看清被遮挡的布局；道具轨迹保留正常三维遮挡，不随楼层裁切。

| 输入 | 操作 |
| --- | --- |
| 鼠标中键拖动／Shift + 中键 | 旋转／平移；平移支持视口边缘循环 |
| 滚轮，W A S D | 缩放，移动相机 |
| Space，←／→ | 播放暂停，步进；协作中切换帧 |
| E，Q | 协作中放人物，打开道具轮盘 |
| 拖动人物，Ctrl／Shift + 拖动 | 移动，调整朝向／俯仰；双击切换蹲姿 |
| Ctrl / Cmd + 点击已放道具 | 移除道具 |
| Ctrl + Z / Ctrl + Shift + Z | 撤销／重做 |
| Ctrl + 1–9 / 0，1–9 / 0 | 保存／恢复相机预设 |
| 触控单指／双指 | 旋转／缩放和平移；外接鼠标键盘仍可用 |

## 模型、设置与备份

导航数据随应用提供，不必导入建筑模型。模型按需加载，关闭后下次启动仍不加载。桌面 **资源包** 可导入 SVG、GLB，或从本机 CS2 导入资源；导入后按提示重新加载。地图导入去除贴图并保留简洁几何与对象树，原始文件不修改。详情见 [资源包说明](ai/references/resource-packs.zh.md)。

设置集中管理字号、各视角的模型面简化、解析采样和存储。桌面分析默认使用缓存，可启用即时处理；数据格式改变会使旧缓存失效。桌面备份包含原生数据和导入资源，不包含原始 Demo、浏览器偏好或未保存工作；清空数据需要输入确认。先导出重要存档与速记，再清理或迁移设备。

## 数据与实验功能

Demo、分析缓存、存档、速记和会话保存在本机。协作和共享回放需要服务器；可选操作助手将本次请求的对话和上下文发送到配置的服务。模型下载和应用更新也需联网。

操作助手是实验功能，可能在构建中关闭。它能读取上下文并调用编辑工具，支持独立会话、记忆、工作流及导入导出；修改结果需自己核对。不会模拟真实投掷物理，也不保证掩体或战术有效。提示词与语料见 [AI 目录](ai/README.md)。

当前房间权限与断线恢复仍有局限，大 Demo 也可能消耗较多内存。遇到问题可附应用版本、步骤和解析详情到 [Issues](https://github.com/dlwm/csBoard/issues)，避免上传私人录像或密钥。

## 实验性操作助手

构建包含 AI 时，对局回放、数据分析与协作面板共用同一个操作助手。在助手设置中配置支持工具调用的模型。请求会向配置的服务发送会话和查询出的证据，不会自动上传整份 Demo。

对局回放中可以询问回合总结或关键事件；证据卡片标明 Demo、回合及原始 tick，点击即可查看。数据分析中先选择选手和 Demo，再询问事件统计或道具推荐。事件统计应用 Demo、选手、回合和事件类型筛选，不应用界面的阵营、经济和空间筛选；道具推荐沿用当前界面筛选。缺失数据及超出单次查询上限的 Demo 会在结果中说明，频次分数不代表战术效果。

准备好的回放跳转与分析筛选需点击才执行，改变选择范围后旧操作可能失效。回放与分析模式不会编辑战术存档或自动保存道具，保存仍使用原有界面。协作面板保留既有编辑工具。上述 AI 功能均为实验性功能。

实验性操作助手可在对局回放与数据分析中展示关联证据的结论卡片、事件片段列表和双栏对比。点击证据才能跳转，展示卡片不会改变视图。卡片随会话保存及导出，重新打开时标记为历史结果；查看前会重新校验当前数据与选择。对比展示两组证据，不会开启两个同步回放视图。
